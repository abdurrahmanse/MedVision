# Welcome to MedVision

MedVision is an enterprise-grade, end-to-end educational platform demonstrating how to deploy a deep learning model in a production-ready web application.

## What You'll Learn

- How to wrap a **PyTorch CNN** in a production FastAPI service
- How to build a **Next.js** frontend that interacts with an inference API
- How to persist prediction records in **PostgreSQL**
- How to orchestrate the full stack with **Docker Compose** and **Turborepo**
