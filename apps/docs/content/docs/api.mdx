## Endpoints

### Health Check

```http
GET /api/v1/health
```

Returns API health and readiness.

**Response**

```json
{ "status": "healthy", "model_loaded": true }
```

---

### Model Info

```http
GET /api/v1/model
```

Returns the currently loaded PyTorch model configuration.

**Response**

```json
{
  "model_name": "tiny-cnn",
  "version": "v1.0.0",
  "task": "binary-classification",
  "classes": ["Normal", "Pneumonia"]
}
```

---

### Run Prediction

```http
POST /api/v1/predictions
Content-Type: multipart/form-data
```

**Rate Limit**: 5 requests per minute.

**Body**

| Field   | Type   | Description                             |
| ------- | ------ | --------------------------------------- |
| `image` | `File` | JPEG or PNG chest X-ray image (max 5MB) |

**Response** `201 Created`

```json
{
  "id": "c9e7f312-4b21-...",
  "predicted_class": "Pneumonia",
  "confidence": 0.9241,
  "model_version": "v1.0.0",
  "image_url": "/storage/uploads/c9e7f312.jpg",
  "created_at": "2024-10-24T14:32:00Z"
}
```

**Error Codes**

| Code                | Status | Description              |
| ------------------- | ------ | ------------------------ |
| `INVALID_FILE_TYPE` | 415    | Only JPEG/PNG accepted   |
| `FILE_TOO_LARGE`    | 413    | Exceeds 5MB limit        |
| `IMAGE_TOO_SMALL`   | 422    | Below minimum resolution |
| `MODEL_UNAVAILABLE` | 503    | Model failed to load     |
| `PREDICTION_FAILED` | 500    | Inference error          |

---

### Get History

```http
GET /api/v1/predictions
```

Returns all prediction records, newest first.

**Rate Limit**: 30 requests per minute.

---

### Get Prediction by ID

```http
GET /api/v1/predictions/{id}
```

| Parameter | Type     | Description                     |
| --------- | -------- | ------------------------------- |
| `id`      | `string` | UUIDv4 of the prediction record |
